# 市场调研工作区

独立入口 `/research`，与能源情报并列。复用现有邮箱/密码登录及 HttpOnly 会话，仅允许现有配置的管理员；调研数据不进入自动采集、分析、通知或情报分类流程。

## 使用

1. 首页先展示市场项目与目标摘要；选择项目进入概览。新建项目填写名称、国家/地区及目标。
2. 概览突出研究目标，按行动计划、客户与伙伴访谈、调研记录、证据与参考资料提供阅读入口；每类显示最近更新的最多三份资料；只有一份HTML时直接阅读手册，多份资料时查看全部进入对应筛选，空分类不显示无效入口。资料库保留添加资料功能。
3. 可以保存正文、来源链接和一个附件。文件支持 HTML、Markdown、TXT、PDF、PNG、JPEG、WebP、DOCX、XLSX、ZIP，每份最多2MiB。正文最多100000字符。
4. 资料库按标题查找、按类型筛选；点击资料进入独立阅读区，返回保留筛选。项目选择、资料库与阅读写入浏览器历史，浏览器返回/前进及刷新恢复对应项目和资料，不会从HTML直接退回能源情报工作台。项目导航不随HTML附件改变布局；附件正文说明默认折叠，纯文字默认展开。手机通过全部项目入口切换项目。文字可编辑，附件原件不可替换，新版附件新增记录。
5. HTML在独立沙箱预览中运行，不能读取站点会话或父页面。手册内的填写不自动写回附件；重要记录应导出备份或保存已填写HTML，再上传新版。

保存到云数据库及私有Storage后可跨设备读取；本页未实现删除、多人权限、自动研究或CRM。未保存的输入在切换/离开前提示；会话到期时有未保存内容则保留输入，提示在另一个窗口登录。

## 存储和安装

- 新增 `research_projects` 与 `research_entries`，按 `owner_id` 过滤；复合外键保证资料与项目属于同一owner。服务端保存记录时忽略客户端owner。
- RLS开启，anon/authenticated无直接表权限；服务角色可select/insert/update。附件存入新私有桶 `nrgopt-research`，不混用情报原件桶，下载经登录API检查并核对SHA-256。
- 文字更新按revision条件原子写入；过期版本返回409，保留当前输入。
- 写入沿用现有 `settings(env).writes` 环境控制。不新增账号、不改变情报自动采集或付费调用开关。
- 在目标数据库仅执行新迁移 `supabase/migrations/202610080050_research_workspace.sql`；不要重放旧迁移。它只新增两张表、索引和私有桶，不改动现有业务行。
- 发布代码和安装迁移是两步。部署前先完成目标库备份/新增迁移/直接读取权限检查，代码上线后检查共享登录、资料保存重读、下载哈希与匿名拒绝。
- 真实出访资料留在公共代码仓库之外，通过登录后的资料上传导入目标环境。源码不包含乌兹别克计划原件、对话或客户信息。

报告交叉阅读：网站导入副本使用 `/research?project=...&file=...` 作为可重开的链接，附件内的同项目链接添加 `data-research-file`。HTML预览桥接只允许打开当前项目已有条目，保持同一阅读区与浏览器返回路径；下载原件包含网站链接。研究原始文件另存受控目录，不进入公共代码仓库。

HTML沙箱允许报告自身调用浏览器打印弹窗（allow-modals），仍不允许same-origin、读取父页面会话或网络请求。原件下载字节不变。
